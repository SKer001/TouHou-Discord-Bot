# 開發紀錄存檔：0.24.xxx

## 0.24.001 — 2026-11-05：神社參拜客列表對齊
- 問題：妖怪名字長度不同 (河童 / 白狼天狗)，後面的心情、報酬欄位對不齊。解法：名字用全形空白補到一樣長，數字放在等寬字型裡靠右對齊。

## 0.24.000 — 2026-11-05：經濟系統私人化、修正上架、管理員指令、漲跌曲線
- `/shrine`、`/market` 全部改成私人查閱 (只有自己看得到)；**上架成功時在頻道公開一則上架公告** (卡面縮圖 + 售價)。
- `/trade`：轉帳紀錄只有轉出人看得到；**收款人會收到私訊通知** (對方關閉私訊時轉帳照樣成功，畫面會提示)。
- 修正：`/market sell` 沒辦法上架。
  - 原因：Discord 把 autocomplete 的顯示名稱整串送進來 (`character: '🧸 愛麗絲 (alice) · 5 張'`，日誌查到的)，不是角色 key，於是被當成「沒有這個角色」。
  - 解法：`resolve_pool` / `resolve_character` 收到顯示名稱時從括號反查 key，`/market` 與 `/admin-market` 都會用。
  - 選單上同角色同完整度的卡長得一模一樣、分不出哪張，選項名稱加上卡片 ID (`#cdab6b`)，說明欄加上取得時間。
- 新增 `/admin-shrine view / set / reset` (調整賽錢箱、清潔度、妖怪、參拜客人數與心情)、`/admin-market set_price / reset_price`、`/admin-trade test_dm` (讓指定玩家收到轉帳通知私訊，賽錢不變)。
- 漲跌曲線改得連續：原本「沒人賣 +2%」但「只賣 1 張」會漲到 +10%，賣越少反而跳很大。
  - 改成：賣得比持平點少 ➔ 從 +2% (沒人賣) 平滑降到 0% (剛好持平)；賣得比持平點多 ➔ 往下跌，3 倍時 −10%。
  - 賣越多一定越便宜，一天最多漲 2%、最多跌 10% (漲得慢、拋售跌得快)。
