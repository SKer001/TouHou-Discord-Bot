## 0.38.000 — 2026-11-23：⚡ 自動合成全部、⚗️ 繼續合成 (筆電，抽卡 session)
- 統整 session 轉來，8 題 grill 都照建議 (使用者回「都好」)。使用者原話：「優化卡牌合成 合成介面可以直接自動合成全部(由最小跟第二小合 循環) 如果是手動選擇合成 合完除了回去卡牌庫 還有繼續合成的選項可以用」
- **⚡ 自動合成全部**：
  - `/card synthesis` 選好角色後的選卡畫面最下面多一顆按鈕。
  - 範圍 = 這位角色，每個階級各自合。從卡冊「⚗️ 合成這一疊」進來也一樣是整位角色。
  - 怎麼合：每次拿完整度最低的兩張 (一樣低先拿比較早取得的)，新卡放回去繼續比，合到只剩一張未滿 1.0000；合到 1.0000 的不再參加。每次照樣 `roll_synthesis` 擲加倍。
  - **確認畫面**：每個階級一行「R：12 張 ➔ 最多合成 11 次」。寫「最多」是因為合到 1.0000 的卡會提早退出，實際次數可能比較少。提醒用掉的卡會消失、加倍隨機、不能還原、想留的卡先放進收藏冊。按「⚡ 確認自動合成」才做。
  - **結果畫面**：每個階級一行 (合成幾次、加倍幾次、剩下那張的完整度、合到 1.0000 的張數)，只留「🎒 查看卡庫」。
- **⚗️ 繼續合成**：
  - 手動合成的結果畫面，「🎒 查看卡庫」旁邊多一顆，回到同一位角色的選卡畫面 (重新讀卡)。
  - 這位角色已經沒有可以合的組合時反灰。
  - 自動合成失敗 (卡牌變了) 時也有這顆，可以回選卡畫面重按。
- 程式：
  - `gacha.py` 新增 `run_auto_synthesis()` (純邏輯，中間合出來又被拿去合的卡不會寫進資料庫)、`auto_synthesis_preview()`、`synthesized_card()` (手動合成也改用它)、`make_auto_synthesis_view()`；`CardActionConfirmView` 多 `continue_character` / `continue_on_success`。
  - 資料層 `udm.auto_synthesize_cards()` 是單一交易 (BEGIN IMMEDIATE)：
    1. 重新讀這位角色卡冊裡的卡 (收藏冊 `locked`、出征中 `expedition` 的不算)。
    2. 跟確認畫面的張數不一樣就整筆不做，提示重按。
    3. 刪舊卡、寫新卡，`total_synths` + 合成次數 (合成稱號一次算一次)。
    4. 寫完 `card_cache.invalidate`。
  - 連按兩下只做一次。
