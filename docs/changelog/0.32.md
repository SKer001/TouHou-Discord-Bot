## 0.32.000 — 2026-11-13：🔒 收藏冊
- **新功能 `/card album`** (使用者要求：可以收藏任意卡，合成、融合、販售等一切會讀到卡的地方，連 autocomplete 都不會出現)：卡冊的單卡詳情多一個「🔒 放進收藏冊」，收藏冊裡選卡 ➔「📤 取出」回到卡冊。
- 做法：`gacha_cards` 加 `locked` 欄位 (`init_db` 自動補)。`get_user_cards()` 預設排除鎖住的卡 ➔ 卡冊、合成、融合、分解、上架、所有 autocomplete (`card_cache`) 一次全部看不到；需要全部的地方 (管理員 `/admin-gacha`、圖鑑已擁有) 改傳 `include_locked=True`。
- 資料層也擋：`transform_cards` (合成 / 融合)、`decompose_cards`、`list_card` 只認 `locked = 0`，繞過選單直接打卡片 ID 也會失敗。
- 使用者選照建議：稱號 (完美卡、推角…)、排行榜卡牌價值都照算 (直接查 SQL，本來就含)；不設容量上限；放進 / 取出免費、沒有冷卻。
- 管理員看別人卡冊時鎖住的卡標「🔒 收藏中」，沒有放進收藏冊按鈕。新測試 `tests/test_album.py` (25 項)。
